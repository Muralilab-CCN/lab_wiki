# 🏛️ Welcome to the Murali Lab Wiki

This is the centralized repository for internal documentation, onboarding resources, instrument guidelines, and experimental protocols for the **Murali Lab at IIT Jodhpur**.

### 🚀 Getting Started
Use the top navigation bar or the search bar at the top right to find information quickly.

### 📝 Contribution Guidelines
All lab members are encouraged to update and maintain these documents. When adding new protocols:
1. Write clearly and include safety/troubleshooting tips.
2. Ensure tables and targets (e.g., impedance levels) are explicit.
3. Deploy updates using `mkdocs gh-deploy`.
